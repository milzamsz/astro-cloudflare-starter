# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Security

- `PUBLIC_CONSENT_ENABLED=true` now actually gates analytics: a consent banner is
  shown and GA/GTM/Umami load only after the visitor accepts (previously the flag
  did nothing and analytics always loaded).
- JSON-LD is serialized with `<`, `>`, `&` escaped so content can't break out of
  its `<script>` element.
- `Strict-Transport-Security: max-age=31536000` header.
- The R2 cleanup endpoint rejects secrets shorter than 32 characters (it isn't
  rate limited).
- trufflehog's scanner image is pinned instead of `:latest`.
- Removed the unused `src/lib/analytics` module (inline-script loader that the CSP
  would block) and the unused `src/config/consent.config.ts`.

## [2.0.0] — 2026-11-18


### Breaking

- Requires **Node.js 26 LTS** and **pnpm 12** (`corepack enable`). pnpm settings
  live in `pnpm-workspace.yaml`.
- **React removed.** `FeatureTabs` is now `src/components/landing/FeatureTabs.astro`
  (`visual` is a plain string, `icon` is a lucide name). `@astrojs/react`, `react`,
  `react-dom`, `cva` are no longer dependencies.
- **Component paths:** `Hero` (+ `hero.variants`), `CTA`, `FAQ` and `FeatureGrid`
  moved to `src/components/sections/`; `components/hero/` and the
  `components/Hero.astro` wrapper are gone. The brand `Logo` is
  `ui/marketing/Logo` (`showName` prop); the presentational CTA is registered as
  `CTAPanel`. The sections barrel's `CTA` takes `ctaText`/`ctaHref`.
- **Locales** are defined only in `src/config/i18n.config.ts`.
- **Linting:** Oxlint for JS/TS, ESLint only for `.astro` files (`.eslintrc.cjs`
  removed), Stylelint without SCSS.
- `typescript` is now the `@typescript/typescript6` compat package (for tooling);
  TypeScript 7 is installed as `typescript-native` and provides `tsc`.
- `POST /api/cleanup` only; other methods return 405.

### Added

- Hash-based Content Security Policy generated by Astro (`security.csp`), sources in
  `src/config/csp.config.ts`; Starlight inline scripts hashed by a small integration.
- Branded `404` page; Starlight `i18n` collection for UI string overrides.
- CI: full lint, unit tests, Playwright e2e (incl. zero CSP violations), Lighthouse
  budgets, SHA-pinned actions; Renovate replaces Dependabot.
- Opt-in scheduled R2 cleanup workflow; Workers types via `wrangler types`.
- Tests for content uniqueness, tag helpers, the cleanup function and the CSP
  hash integration; keyboard tests for the tabs.

### Changed

- Every dependency upgraded to its latest major (Astro 7.4, MDX 8, Starlight 0.43,
  Tailwind 4.3, Vitest 5, Stylelint 18, Playwright 1.65, Pagefind 1.6, …).
- Analytics, header, search and theme-toggle scripts are bundled (no `is:inline`).
- Alert / form error colors use semantic tokens; `check:kpis` reports 0 warnings.
- Screenshots moved to `docs/assets/` as WebP.

### Fixed

- Tag counts and tag filtering ignored real content entries (tags live in
  `entry.data.tags`).
- R2 cleanup read its manifest from R2, where nothing uploads it; a missing manifest
  made every object eligible. It now loads `/media-manifest.json` from the deployed
  site and aborts if that fails.
- `pnpm lint` failed on `Analytics.astro`; CI's dependency-review and secret-scanning
  jobs were broken.
- Docs claimed Indonesian routes, a cron trigger and an OpenStreetMap embed that
  didn't exist.

## [1.0.0] — 2026-06-27

Initial public template release.

### Highlights

- Astro 7 + TypeScript, Tailwind CSS v4, monochrome OKLCH design tokens
- Bilingual content (English / Indonesian) with prefix-based i18n routing
- Git-based content (Markdown) — no CMS or database
- Marketing pages, blog, and Starlight docs with Pagefind search
- Cloudflare Pages hosting with optional R2 media + secret-guarded cleanup worker
- SEO: canonical, hreflang, JSON-LD, Open Graph, sitemap, RSS, dynamic `llms.txt`
- Static contact page (mailto + OpenStreetMap embed)
